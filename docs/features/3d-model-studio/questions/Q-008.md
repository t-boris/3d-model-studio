## Question

Should v1 open 3MF files that use the 3MF Production extension, such as multi-part project files saved by Bambu Studio or Orca Slicer?

## Why it matters

REQ-002 requires 3MF import, and the current importer accepts only Core 3MF with a single internal model part. It rejects files that declare required extensions or reference other model parts, which includes many slicer project files.

## Options

- **A**: Keep v1 to Core 3MF with a single model part. When a file uses the Production extension, explain that it is not supported and ask the user to export a Core 3MF mesh.
- **B**: Support the Production extension in v1. Read every referenced model part, apply its transforms and flatten all parts into one editable mesh. Add fixtures from Bambu Studio and Orca Slicer to the acceptance checks.

## Recommended

A

## Answer

B. Support the Production extension in v1. Read every referenced model part, apply its transforms and flatten all parts into one editable mesh. Add fixtures from Bambu Studio and Orca Slicer to the acceptance checks.
