## Question

How should the REQ-009 dimension checks in PrusaSlicer be performed and recorded?

## Why it matters

REQ-009 requires measured X, Y and Z dimensions in PrusaSlicer for two exported models but does not say which PrusaSlicer release to use or how to measure. PrusaSlicer is not installed on the current development Mac.

## Options

- **A**: Read the dimensions from the PrusaSlicer command line (the --info output) in a repeatable script, and open each export once in the PrusaSlicer window to confirm it loads without a rescaling prompt. Record the PrusaSlicer version with the evidence.
- **B**: Open each export in the PrusaSlicer window and read the dimensions from the object information panel. Record the PrusaSlicer version and screenshots with the evidence.

## Answer

A. Read the dimensions from the PrusaSlicer command line (the --info output) in a repeatable script, and open each export once in the PrusaSlicer window to confirm it loads without a rescaling prompt. Record the PrusaSlicer version with the evidence.
