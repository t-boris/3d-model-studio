## Question

How should the exported Core 3MF file be structured?

## Why it matters

The importer flattens 3MF build items and components into one indexed mesh, so the workspace no longer holds the source object structure. The exporter and the PrusaSlicer acceptance check need a defined structure.

## Options

- **A**: Write one mesh object and one build item with no transform. The object contains the current flattened mesh in millimeters, with the model name as the object name.
- **B**: Preserve the source 3MF objects, components and build items when exporting a model imported from 3MF. This requires keeping that structure in the workspace model.

## Recommended

A

## Answer

B. Preserve the source 3MF objects, components and build items when exporting a model imported from 3MF. This requires keeping that structure in the workspace model.
