## Question

What should slicer export do when the current mesh fails the REQ-007 print checks (degenerate or duplicate faces, open or non-manifold edges, inconsistent winding)?

## Why it matters

Core 3MF requires objects of type "model" to be closed manifold meshes, so exporting failing geometry produces a file that does not conform to the format. REQ-009 does not cover this case, and the exporter's behavior and its acceptance tests depend on the answer.

## Options

- **A**: Block export until the print checks pass, and show the failing checks with the affected faces and edges.
- **B**: Run the print checks before export. If they fail, show the defects and export only after the user confirms. If they pass or the user confirms, write the file.
- **C**: Export the current mesh without running the print checks or warning the user.

## Recommended

B

## Answer

A. Block export until the print checks pass, and show the failing checks with the affected faces and edges.
