## Question

Какой результат для проектирования физических деталей обязателен уже в первой версии?

## Why it matters

Вы выбрали также проектирование для изготовления; нужно отличить интерес к этому применению от обязательных гарантий точности и пригодности результата.

## Options

- **A**: В первой версии достаточно работы с формой; точные размеры и пригодность для изготовления пока не обязательны.
- **B**: В первой версии обязательны точные размеры, но пригодность модели для изготовления пользователь проверяет отдельно.
- **C**: В первой версии обязательны точные размеры и проверка геометрии на пригодность к 3D-печати.

## Recommended

A — Это сохраняет заявленную простоту первой версии при поддержке обоих основных сценариев.

## Answer

C. В первой версии обязательны точные размеры и проверка геометрии на пригодность к 3D-печати.
