## Finding

REQ-003 requires verification of user-requested dimensions. The provider guide documents local recognition of common phrases and delegates other phrasing to the provider that proposes the geometry. If the provider omits or misstates a supported dimension, checking the proposed mesh against the returned targets alone can pass while the user's actual target is unmet. The specification does not establish whether the preview confirms the interpreted targets or simply displays them.

> The provider interprets other phrasing as final axis spans or reports an unsupported constraint.

## Possible interpretations

- Для формулировок, которые приложение не распознаёт самостоятельно, пользователь подтверждает или исправляет значения перед применением правки.
- Приложение принимает только те формулировки размеров, которые может проверить самостоятельно, и просит переформулировать остальные.

## Resolution

Приложение просит указать каждый нераспознанный размер в поддерживаемом виде, например «итоговый размер по X — 30 мм». После этого оно самостоятельно извлекает значения и проверяет геометрию. — see DEC-011.
