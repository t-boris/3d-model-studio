## Finding

The requirement identifies the target but places no enforceable boundary on the changes. An operation such as extrusion can affect adjacent topology. The specification leaves open what the user authorizes by selecting faces and who authorizes any broader change.

> The agent uses the selection as the target of the requested edit.

## Possible interpretations

- Changes beyond the selected region require a separate confirmation, including changes needed to keep neighboring geometry connected.
- The selection permits consequential edits to connected geometry when required by the requested operation.

## Resolution

Если вытягивание выбранной грани сдвинет общую вершину или перестроит соседнюю грань, приложение покажет затронутую область и запросит подтверждение до применения правки. — see DEC-009.

## Implementation evidence

DEC-009 is implemented in 502fe64. Tests/SelectionChecks.swift exercises scoped and outside-selection changes on the new block and every import format, including explicit confirmation after read approval. It also checks shared vertices, topology changes without coordinate movement, and height conflicts after confirmation. Interactive and live service verification remain outstanding.

## Current plan I-4 evidence

Tests/SelectionChecks.swift verifies candidate-specific confirmation on the three scripted routes, with shared-vertex movement, edge winding, same-position vertex splitting, removed faces and disconnected additions. Multipart subdivision keeps the original selection boundary, shows removed and added faces in the respective SceneKit previews, retains ownership of new faces and leaves sibling geometry unchanged. Discard, stale confirmation, missing local targets and conflicting current pins preserve the model.

## I-4 re-verification

The 8e0925f selection harness rejected a read-access ID and a discarded candidate’s ID as edit confirmation. A candidate that subdivided a selected triangle highlighted the removed face on the original, three new faces on the candidate and incident neighbors on both. Decline preserved the mesh. After a valid confirmation, the SceneKit coordinator displayed the exact reviewed mesh, including the new face IDs. The built native app separately exercised picking and scoped instruction entry.
