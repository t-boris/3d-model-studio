## Finding

The required modeling outcomes are underspecified at the level that determines the geometry architecture. Precise dimensions can describe a one-time edit or a constraint that remains in force during later edits. That distinction changes what the application must store and what manual and conversational operations must preserve.

> Users can provide explicit dimensions and units when requesting geometry creation or revision.

## Possible interpretations

- A dimension is a target for the current edit and may change in subsequent edits.
- An explicitly set dimension remains a constraint until the user changes or removes it.

## Resolution

По умолчанию размер действует на одну правку. Пользователь может явно закрепить его, чтобы сохранить при последующих ручных и AI-правках. — see DEC-005.
