## Finding

The core workflow ends with an in-app model. The specification does not establish whether users can save and reopen editable work or export a result for a slicer. These are separate user outcomes and affect what geometry and project state must survive beyond the session.

> In v1, validate model geometry for 3D printing and present actionable results against documented validation criteria.

## Resolution

Пользователь может закрыть редактируемую работу, открыть её позже и продолжить правки, а также выгрузить текущую геометрию для слайсера. — see DEC-006.

## Implementation evidence

REQ-008 records editable save and reopen, including editing and exporting without the original assembly. I-6 verified that the REQ-007 native inspector uses the workspace’s face IDs and indexed edges, marks an earlier result outdated after edits and shows a current pass after repair. REQ-009 uses the same checks for the source and serialized Core mesh. The export suite passed validation, correction, atomic replacement and assembly placement. The two PrusaSlicer CLI acceptance files and results are in Fixtures/Export. Their GUI openings remain pending.
