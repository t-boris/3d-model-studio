## Finding

The core workflow ends with an in-app model. The specification does not establish whether users can save and reopen editable work or export a result for a slicer. These are separate user outcomes and affect what geometry and project state must survive beyond the session.

> In v1, validate model geometry for 3D printing and present actionable results against documented validation criteria.

## Resolution

Пользователь может закрыть редактируемую работу, открыть её позже и продолжить правки, а также выгрузить текущую геометрию для слайсера. — see DEC-006.

## Implementation evidence

REQ-008 records the editable save and reopen behavior. REQ-007 covers the active indexed mesh and presents affected face IDs, assembly occurrence labels, edge endpoints and corrective guidance. DEC-010 settles Core 3MF in millimeters as the export format, and DEC-014 requires the exact exported mesh to pass REQ-007. Export implementation and PrusaSlicer acceptance remain in I-8.
