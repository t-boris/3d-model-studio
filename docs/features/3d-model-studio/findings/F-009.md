## Finding

REQ-008 defines what an explicit save restores. REQ-002 preserves the active workspace on canceled or failed imports. Neither specifies what happens to unsaved geometry or pin changes when a successful Open replaces the active model or the user quits. This determines whether those actions can silently lose work.

> The system shall save an edited model created in the workspace or imported from a supported format and reopen it for continued editing.

## Possible interpretations

- Перед заменой модели или выходом предложить сохранить правки, отказаться от них или отменить действие.
- Автоматически сохранять рабочую копию с правками и закреплёнными размерами, чтобы её можно было восстановить после замены модели или выхода.

## Resolution

Перед заменой модели или выходом предложить «Сохранить», «Не сохранять» и «Отмена». Запрашивать решение при изменении геометрии, добавлении, изменении или снятии закреплённого размера. — see DEC-012.

## Implementation evidence

DEC-012 uses the shared Open and Quit decision. An interrupted discard retains the active model and its dirty baseline. Tests/run-workspace-file-checks.sh covers both actions after geometry changes and each independent pin mutation, including failed saves and interrupted replacements. The current Debug build showed the same three choices for Command-O and Command-Q. Cancel and canceling the Quit save panel retained the edited assembly. Save persisted it and completed Quit. Discard Changes also completed Quit after a pin-only change.
