## Finding

The specification names no required import formats and does not establish whether the viewing and editing format sets are identical. This leaves the v1 compatibility promise untestable and affects importer selection and the geometry editing pipeline.

> An imported model can proceed into the manual and conversational editing workflows within the supported v1 capabilities.

## Possible interpretations

- Every format supported for viewing must also support manual and conversational editing.
- A broader set of formats can be viewed, with editing available for a documented subset.

## Resolution

STL, OBJ и 3MF можно открывать, просматривать и редактировать вручную и через AI. — see DEC-004.

## Implementation evidence

The three required formats now import into the same editable mesh. Fixtures/Import contains a matching block for each format and expected units, topology, and height edit. I-2 checked the shared representation, source-unit conversion, editability of shared vertices, and SceneKit geometry using interpreted Swift. User-facing manual and conversational acceptance runs remain under I-4 and I-6.
