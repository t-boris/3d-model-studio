## Finding

DEC-006 requires slicer export and explicitly leaves the format open. REQ-009 and I-9 record the resulting implementation block. The format and reference slicer need to be selected together because the acceptance test must demonstrate that the exported mesh opens at the correct physical size.

> Users can export the current mesh of a new or imported model in the agreed slicer-compatible format while preserving its physical dimensions.

## Possible interpretations

- Экспортировать 3MF с явно заданной единицей и проверять масштаб в выбранном слайсере.
- Экспортировать STL с координатами в миллиметрах и проверять масштаб в слайсере, который интерпретирует их как миллиметры.

## Resolution

Экспортировать текущую сетку в Core 3MF с явно указанными миллиметрами. Единица измерения хранится в файле. Эталонный слайсер — PrusaSlicer. — see DEC-010.
