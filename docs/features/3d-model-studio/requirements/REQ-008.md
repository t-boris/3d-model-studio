## Statement

Save and reopen editable models created in the workspace or imported from a supported format. For 3MF imports, preserve the assembly structure and its association with edited geometry across save and reopen. Before replacing the active model or quitting, offer Save, Discard Changes, and Cancel when geometry or an explicitly pinned dimension has changed since the last save, including adding or removing a pin.

## Acceptance Criteria

- [ ] Reopening an editable save restores the edited indexed geometry, face identities, model length unit, and all explicitly pinned dimensions with their targets and units. Dimensions supplied only for a completed operation have expired.
- [ ] After saving and reopening an edited 3MF assembly, the user can continue editing and export the restored object, component, and build-item structure under REQ-009 without the original 3MF file.
- [ ] Existing editable saves reopen with their stored geometry, unit, face identities, and pins.
- [ ] A reopened model accepts edits through the same dimensional checks. A conflicting edit identifies the violated dimension and preserves the current geometry and pins.
- [ ] For a newly created or imported model, unsaved geometry changes and each kind of pin change independently trigger the prompt before replacement or quit.
- [ ] Save continues only after successful persistence. Cancel, a canceled save dialog, or a save failure stops the requested action and preserves the model and edits. Discard Changes continues without saving. If opening a replacement subsequently fails or is canceled, the active model and edits remain open.
