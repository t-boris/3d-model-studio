## Statement

Save and reopen editable models created in the workspace or imported from a supported format. For 3MF imports, preserve the assembly structure and its association with edited geometry across save and reopen. Before replacing the active model or quitting, offer Save, Discard Changes, and Cancel when geometry or an explicitly pinned dimension has changed since the last save, including adding or removing a pin.

## Acceptance Criteria

- [x] Reopening an editable save restores the edited indexed geometry, face identities, model length unit, and all explicitly pinned dimensions with their targets and units. Dimensions supplied only for a completed operation have expired.
- [ ] After saving and reopening an edited 3MF assembly, the user can continue editing and export the restored object, component, and build-item structure under REQ-009 without the original 3MF file.
- [x] Existing editable saves reopen with their stored geometry, unit, face identities, and pins.
- [x] A reopened model accepts edits through the same dimensional checks. A conflicting edit identifies the violated dimension and preserves the current geometry and pins.
- [x] For a newly created or imported model, unsaved geometry changes and each kind of pin change independently trigger the prompt before replacement or quit.
- [x] Save continues only after successful persistence. Cancel, a canceled save dialog, or a save failure stops the requested action and preserves the model and edits. Discard Changes continues without saving. If opening a replacement subsequently fails or is canceled, the active model and edits remain open.

## Implementation evidence

Tests/run-workspace-file-checks.sh reads a fixed archive generated by the original version-1 writer at faf6658. It restores the edited block, its face identities and its 1-inch width pin, rejects a conflicting width and accepts a new height. The same test saves an extruded repeated assembly, removes its source package copy and reopens the archive in a fresh workspace. The full indexed mesh, next face ID, units, pins, objects, build references and occurrence paths match, including generated wall ownership. Further extrusion from a saved wall retains that ownership. The archive portion of criterion 2 is verified. I-8 owns the Core 3MF export portion.

For new and imported models the test isolates geometry, pin addition, pin change with identical geometry, and pin removal against an actual successful save. Each prompts independently for both Open and Quit. Restoring the saved values clears the prompt. Tests cover canceled and failed saves, disk contents before the replacement picker, discard without a write, canceled or failed pickers, failed imports and canceled or failed unit selection. A separate interpreted AppKit run exercised the production termination delegate and native alert. Cancel retained the pinned model and Discard Changes completed termination.
