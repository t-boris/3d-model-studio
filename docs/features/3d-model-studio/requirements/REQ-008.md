## Statement

The system shall save an edited model created in the workspace or imported from a supported format and reopen it for continued editing.

## Acceptance Criteria

- [x] An editable save from either origin restores the edited indexed geometry, face identities, and model length unit.
- [x] Reopening restores every explicitly pinned dimension with its target and unit. Dimensions supplied only for a completed operation expire.
- [x] The reopened model accepts subsequent geometry edits through the same dimensional checks. A conflicting edit identifies the violated dimension and preserves geometry and pins.

## Implementation evidence

Tests/run-dimension-checks.sh saved and reopened an edited new block and each STL, OBJ and centimeter 3MF fixture in a fresh workspace. It compared the full indexed geometry and face IDs, model unit and two pins, including a width pin entered in inches. Reopened geometry accepted another height, rejected a conflicting width and accepted a new width after unpinning. Invalid archives preserved the active model. SwiftUI file panels are wired and type-checked. Interactive panel verification awaits a build-enabled step.
