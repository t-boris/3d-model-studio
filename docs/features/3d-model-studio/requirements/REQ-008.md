## Statement

The system shall save an edited model created in the workspace or imported from a supported format and reopen it for continued editing.

## Acceptance Criteria

- [ ] An editable save from either origin restores the edited indexed geometry, face identities, and model length unit.
- [ ] Reopening restores every explicitly pinned dimension with its target and unit. Dimensions supplied only for a completed operation expire.
- [ ] The reopened model accepts subsequent geometry edits through the same dimensional checks. A conflicting edit identifies the violated dimension and preserves geometry and pins.
