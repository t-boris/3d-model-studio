## Statement

Provide a native macOS application with a Swift user interface. In v1, users can install 3D Model Studio, launch it from Finder, and connect Codex, Claude, and Antigravity through the application UI, including completing authentication for each provider. The application provisions the required provider components. Setup requires no separate Docker installation. Release acceptance on a clean Mac without Docker Desktop installed must demonstrate that a user can install the application, launch it from Finder, connect all three agents through the application UI, and complete a conversational modeling operation with each agent.

## Acceptance Criteria

- [ ] The application runs on macOS.
- [x] The application UI is implemented in Swift.
- [ ] On a clean Mac without Docker Desktop installed, a user can install the v1 application.
- [ ] The user can launch the installed application from Finder.
- [ ] When the user connects each provider, the application provisions the required components for Codex, Claude, and Antigravity.
- [ ] The user can connect Codex through the application UI and complete authentication.
- [ ] The user can connect Claude through the application UI and complete authentication.
- [ ] The user can connect Antigravity through the application UI and complete authentication.
- [ ] The user can complete provider setup without separately installing Docker.
- [ ] Release acceptance on the same clean Mac demonstrates that the user can complete a conversational modeling operation with each of the three agents after connecting them.
