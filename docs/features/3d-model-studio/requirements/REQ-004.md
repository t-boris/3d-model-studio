## Statement

Provide direct manual geometry editing, including point movement, surface reshaping, extrusion, and precise numerical dimension control.

## Acceptance Criteria

- [ ] Users can move points, reshape surfaces, and extrude selected geometry.
- [ ] Users can inspect and numerically set dimensions in explicit units.
- [ ] Numerically specified edits produce geometry matching the entered dimensions within a documented numerical tolerance.
