## Statement

Provide direct manual geometry editing, including point movement, surface reshaping, extrusion, and precise numerical dimension control. Check entered dimensions against the documented numerical tolerance when applying the operation that sets them. By default, an entered dimension applies only to that operation. Users can explicitly pin a dimension on a new or imported model to preserve it across subsequent manual and AI edits until they change or unpin it. Before applying each subsequent edit, check the proposed geometry against all pinned dimensions using the same tolerance. Reject any edit that violates a pinned dimension and identify the conflicting dimension.

## Acceptance Criteria

- [x] Users can move points, reshape surfaces, and extrude selected geometry.
- [x] Users can inspect and numerically set dimensions in explicit units.
- [x] A numerically specified edit is applied only if the resulting geometry matches the entered dimensions within the documented numerical tolerance.
- [x] By default, an entered dimension applies only to the operation that sets it.
- [x] Users can explicitly pin and unpin dimensions on both new and imported models.
- [x] A pinned dimension remains in force until the user changes or unpins it.
- [x] Before applying each subsequent manual or AI edit, the app checks the proposed geometry against every pinned dimension using the same documented numerical tolerance.
- [x] If a proposed edit would violate a pinned dimension, the app rejects the edit and identifies the conflicting dimension.

## I-3 implementation evidence

The workspace displays model-axis extents and accepts numerical lengths in six units. Tests/run-dimension-checks.sh exercises Set Once, pin changes, failed edits and continued editing after reopen. The same ±0.01 mm interval governs requested and pinned dimensions.

## V1 manual tools

Pick a shared point and move it by a signed distance along X, Y or Z. Reshape one or more selected triangles by moving their shared vertices once along the chosen axis. Extrude a triangle or a connected, consistently oriented planar patch a positive distance along its normal. Preserve the selected face IDs on the cap and join its boundary to the starting surface with side triangles. In an imported 3MF assembly, assign the side triangles to the occurrence that owns the selected cap. Enter the distance in any supported unit. The workspace transaction checks the resulting displacement and current model pins before publishing the edit.

## I-4 implementation evidence

The SwiftUI workspace exposes Move Point, Reshape Surface and Extrude with viewport picking, highlighted selection and explicit distance units. Tests/run-manual-edit-checks.sh exercised all three on a new block and the single-part import fixtures through Workspace.applyManualEdit. SceneKit ray hits identified a selected cap triangle, and the viewport geometry reflected successful edits. Each tool rejected a height conflict with the dimension name and preserved the full mesh and pins. Checks also covered a signed reverse move, unrepresentable displacement and unsupported patches. I-6 and I-7 exercised whole-model and selected-face AI edits against the same transaction, including a pin set after review opened.

## Current plan I-2 evidence

Commit bc20e9f prepares manual edits inside the shared workspace transaction and publishes geometry and pins after all checks pass. The manual and dimension suites verified both inclusive ±0.01 mm limits and rejection just outside them on a new block and the STL, OBJ and centimeter Core 3MF fixtures. The assembly suite also exercised all three tools on the Bambu Studio, OrcaSlicer and repeated mixed-unit fixtures. Extrusion kept the cap face IDs, assigned the walls to the cap’s occurrence and preserved sibling geometry. The native Debug app moved a point from Z 10 mm to 11 mm after unpinning, reshaped the surface to 12 mm, and extruded a selected two-triangle patch from 12 to 20 faces while retaining both selected faces. Before unpinning, the native point move named the pinned height and retained the 10 mm point, span and pin. Native Set Once, Change Pin in centimeters and Unpin also passed.

## Review interaction updates

The left tool palette exposes Orbit, Move Point, Reshape Surface and Extrude. In an editing mode a mouse drag applies a model edit through Workspace.applyManualEdit. Point and surface movement follow the view plane, while extrusion follows the flat patch’s outward normal. Native checks moved a point, reshaped a triangle and extruded a top-view two-triangle patch from 12 to 20 faces while keeping both selected. A pinned-width drag reported the conflict and preserved the point and pin. The manual suite verified the workspace transaction for a 3–4–5 mm movement across new, STL, OBJ and centimeter 3MF geometry, and checked inclusive displacement limits separately. The numerical controls still support exact axes and units.
