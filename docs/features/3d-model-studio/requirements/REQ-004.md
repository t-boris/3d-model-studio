## Statement

Provide direct manual geometry editing, including point movement, surface reshaping, extrusion, and precise numerical dimension control. Check entered dimensions against the documented numerical tolerance when applying the operation that sets them. By default, an entered dimension applies only to that operation. Users can explicitly pin a dimension on a new or imported model to preserve it across subsequent manual and AI edits until they change or unpin it. Before applying each subsequent edit, check the proposed geometry against all pinned dimensions using the same tolerance. Reject any edit that violates a pinned dimension and identify the conflicting dimension.

## Acceptance Criteria

- [ ] Users can move points, reshape surfaces, and extrude selected geometry.
- [ ] Users can inspect and numerically set dimensions in explicit units.
- [ ] A numerically specified edit is applied only if the resulting geometry matches the entered dimensions within the documented numerical tolerance.
- [ ] By default, an entered dimension applies only to the operation that sets it.
- [ ] Users can explicitly pin and unpin dimensions on both new and imported models.
- [ ] A pinned dimension remains in force until the user changes or unpins it.
- [ ] Before applying each subsequent manual or AI edit, the app checks the proposed geometry against every pinned dimension using the same documented numerical tolerance.
- [ ] If a proposed edit would violate a pinned dimension, the app rejects the edit and identifies the conflicting dimension.
