## Statement

Export the current edited geometry of new and imported models for slicing in Core 3MF only. Explicitly declare millimeters, express coordinates in millimeters, and preserve physical dimensions. For 3MF imports, preserve the source object and component hierarchy and build items in Core 3MF, including when the source uses Production model-part references. Require the exact mesh being exported to pass all REQ-007 checks. On failure, block export and show the failed checks and affected geometry. Use PrusaSlicer as the reference slicer.

## Acceptance Criteria

- [ ] Core 3MF is the sole slicer export format. The file contains the current edited geometry, uses millimeter coordinates, and explicitly declares millimeters as its model unit.
- [ ] A passing REQ-007 result applies to the exact mesh written. If a check fails, the app shows the failing checks and affected faces and edges where applicable, leaves the destination unchanged, and permits export after the corrected mesh passes.
- [ ] An edited multipart 3MF import retains its object and component hierarchy and build items in the Core export, with equivalent physical placement and no Production extension dependency. Editing one repeated occurrence changes only that occurrence in the export. The same checks pass after saving and reopening the editable model.
- [ ] Verify an edited app-created model and an edited imported model whose source unit differs from millimeters. A repeatable script reads PrusaSlicer `--info` and compares the reported X, Y, and Z dimensions with the corresponding expected physical dimensions within the documented tolerance. Verify transformed assembly placement separately if the CLI reports object-local bounds.
- [ ] Open each acceptance export once in the PrusaSlicer window and confirm it loads without a rescaling prompt or manual rescaling. Record the PrusaSlicer version, CLI output, expected dimensions, and GUI result.
