## Statement

Users can export the current mesh of a new or imported model in the agreed slicer-compatible format while preserving its physical dimensions.

## Acceptance Criteria

- [ ] A compatible slicer opens the exported geometry of an edited, newly created model with the expected physical dimensions.
- [ ] A compatible slicer opens the exported geometry of an edited, imported model with the expected physical dimensions, including when its source coordinates use a unit other than millimeters.
