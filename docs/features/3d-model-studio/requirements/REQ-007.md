## Statement

In v1, validate model geometry for 3D printing and present actionable results against documented validation criteria.

## Acceptance Criteria

- [x] Users can run geometry validation on new and imported models after manual or AI edits.
- [x] Validation reports whether the model passes the documented geometry checks and identifies detected issues and affected geometry.
- [x] Validation results become visibly outdated when subsequent geometry changes require revalidation.
- [x] The application states the scope of its geometry checks without presenting a passing result as a guarantee of successful physical printing.

## V1 geometry checks

Check the indexed triangle surface. Every triangle must have twice its area greater than 10⁻¹² times its longest squared edge length. Each unordered triple of vertex indices must occur only once. Each nonzero indexed edge must belong to exactly two distinct faces, traversed in opposite directions. Report offending face IDs and edge endpoints where applicable. A pass covers these local checks only. Self-intersections, absolute shell orientation, wall thickness, printer settings and material behavior are outside their scope.

## Implementation evidence

f7dbc19 adds Print Checks to the workspace and defines its limits in the inspector and README. Interpreted production checks passed after manual edits of a new block and all three import fixtures, and after scripted provider revisions across all 12 provider/origin combinations. Defect checks covered degenerate and duplicate faces, open and non-manifold edges, and inconsistent winding. Removing a face reported exactly its three boundary edges and their incident face IDs. SceneKit checks verified the selected face group, edge line and corner marker. Edits, repairs, resize and in-flight changes invalidated results. Pin metadata, rejected edits and canceled opens retained them. Replacement models started unchecked. The app sources type-checked for macOS 14. Interactive window verification is pending because building was disabled.
