## Statement

In v1, validate model geometry for 3D printing and present actionable results against documented validation criteria.

## Acceptance Criteria

- [x] Users can run geometry validation on new and imported models after manual or AI edits.
- [x] Validation reports whether the model passes the documented geometry checks and identifies detected issues and affected geometry.
- [x] Validation results become visibly outdated when subsequent geometry changes require revalidation.
- [x] The application states the scope of its geometry checks without presenting a passing result as a guarantee of successful physical printing.

## V1 geometry checks

Check the indexed triangle surface. Every triangle must have twice its area greater than 10⁻¹² times its longest squared edge length. Each unordered triple of vertex indices must occur only once. Each edge between distinct vertex indices must belong to exactly two distinct faces, traversed in opposite directions. Report offending face IDs and edge endpoints where applicable. A pass covers these local checks only. Self-intersections, vertex-only contacts, absolute shell orientation, wall thickness, printer settings and material behavior are outside their scope.

## Implementation evidence

f7dbc19 added Print Checks to the workspace. b3bfd0d added outlines visible through occlusion or line collapse, a point marker, and 3MF occurrence labels. The inspector uses the current indexed surface and explains the limits of a pass. Geometry edits invalidate a current report, and an edit during validation prevents a late report from publishing. Pin metadata, rejected edits and canceled opens preserve a current report. A replacement model starts unchecked.

## Issue inspection

Select a failed check to see all implicated face IDs, an outline of those faces and a suggested correction. Indexed edge issues show the exact edge between its endpoints. A corner marker locates a face collapsed to a point. For a 3MF assembly, the inspector identifies the build item and component path for the affected occurrence. These highlights use the mesh snapshot of the current report.

## I-6 regression evidence

The macOS arm64 Debug app built with Xcode 27.2. On both a new 10 mm block and the Bambu Studio Production fixture, Run Checks passed before editing. Move Point collapsed two faces, made the pass visibly outdated, and exposed the affected IDs, outlines and guidance on recheck. The assembly report identified faces 16 and 19 as Build item 2 · Component 1. Reversing the point move made each failure outdated, and rerunning the inspector passed. A generated multi-item Core 3MF showed all five defect categories. For example, non-manifold edge 0–1 identified faces 0, 4 and 12, and point-collapsed face 48 showed the corner marker. Selecting rows changed the details and viewport highlights together.

The manual suite checked failure and repair through Move Point across seven origins. c223951 verifies the actual endpoints of SceneKit edge overlays and adds open-edge failure and repair to all 12 scripted whole-model provider and origin combinations. Each surviving face retained its ID across removal and the repaired surface passed with a newly allocated face ID. Nine scripted multipart selection cases checked duplicate and non-manifold failures, affected IDs, occurrence paths and repair. Manual, provider, assembly, dimension, workspace-file and export suites passed. Build and verification logs are under `.dde/cache/i6/`.
