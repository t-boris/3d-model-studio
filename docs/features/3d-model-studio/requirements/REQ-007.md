## Statement

In v1, validate model geometry for 3D printing and present actionable results against documented validation criteria.

## Acceptance Criteria

- [ ] Users can run geometry validation on new and imported models after manual or AI edits.
- [ ] Validation reports whether the model passes the documented geometry checks and identifies detected issues and affected geometry.
- [ ] Validation results become visibly outdated when subsequent geometry changes require revalidation.
- [ ] The application states the scope of its geometry checks without presenting a passing result as a guarantee of successful physical printing.
