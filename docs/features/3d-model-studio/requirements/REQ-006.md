## Statement

In v1, integrate Codex, Claude, and Antigravity as configurable background agents for conversational modeling, with agent and model selection in settings.

## Acceptance Criteria

- [ ] Settings allow users to select Codex, Claude, or Antigravity as the active background agent.
- [ ] Settings allow users to select a model supported by the active agent.
- [ ] Subsequent conversational modeling requests use the selected agent and model.
- [ ] Each of the three integrations supports conversational model creation, revision, and edits targeting selected faces.
