## Statement

In v1, support conversational creation of new 3D geometry and iterative conversational refinement of new and imported models, including explicit dimensional constraints.

## Acceptance Criteria

- [ ] Users can provide explicit dimensions and units when requesting geometry creation or revision.
- [ ] Applied geometry changes satisfy the requested dimensions within a documented numerical tolerance; unsupported constraints are reported explicitly.
