## Statement

In v1, support conversational creation of new 3D geometry and iterative conversational refinement of new and imported models, including explicit dimensional constraints. By default, an explicit dimension applies only to the operation that sets it. Users can explicitly pin a dimension on a new or imported model to preserve it across subsequent manual and AI edits until they change or unpin it.

## Acceptance Criteria

- [ ] Users can provide explicit dimensions and units when requesting geometry creation or revision.
- [ ] Before applying a creation or revision operation, the app verifies that the resulting geometry satisfies the requested dimensions within the documented numerical tolerance.
- [ ] The app explicitly reports unsupported dimensional constraints.
- [ ] An explicit dimension applies only to the operation that sets it by default.
- [ ] Users have explicit controls to pin and unpin dimensions on new and imported models and can change a pinned dimension.
- [ ] A pinned dimension remains in force until the user changes or unpins it.
- [ ] Before applying each subsequent manual or AI edit, the app checks the proposed geometry against every pinned dimension using the same documented numerical tolerance used for requested dimensions.
- [ ] If a proposed manual or AI edit violates a pinned dimension, the app rejects the edit and identifies the conflicting dimension.
