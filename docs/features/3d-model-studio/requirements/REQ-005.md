## Statement

Allow conversational AI edits to target explicitly selected faces.

## Acceptance Criteria

- [ ] A user can select one or more faces.
- [ ] A user can issue an AI instruction referring to the selection.
- [ ] The agent uses the selection as the target of the requested edit.
- [ ] The resulting geometry change appears in the viewport.
