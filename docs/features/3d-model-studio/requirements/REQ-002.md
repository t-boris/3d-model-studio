## Statement

In v1, open and display existing STL, OBJ, and 3MF models with standard viewport navigation, and import them as editable geometry for subsequent manual and conversational AI refinement within the supported v1 capabilities defined in REQ-003 through REQ-005.

## Acceptance Criteria

- [ ] For each format (STL, OBJ, and 3MF), a user can open an existing model and inspect it by rotating and zooming the viewport.
- [x] For each format (STL, OBJ, and 3MF), the import pipeline produces editable geometry that a user can refine through the manual editing workflow defined in REQ-003 through REQ-005, within the supported v1 capabilities.
- [x] For each format (STL, OBJ, and 3MF), a user can refine the imported geometry through the conversational AI editing workflows defined in REQ-003 through REQ-005, within the supported v1 capabilities.

## Import contract

Open produces an indexed editable mesh with stable face identifiers and shared vertex references. Coordinates retain the model unit. STL and OBJ require the user to choose the source unit. Core 3MF uses its model unit (millimeters by default) and applies build-item and component transforms. Canceling Open, canceling the unit choice, or encountering an import error preserves the active workspace. I-4 and I-6 use the same imported geometry for their respective acceptance checks.
