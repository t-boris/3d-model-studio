## Statement

In v1, open and display existing STL, OBJ, and 3MF models with standard viewport navigation, and import them as editable geometry for subsequent manual and conversational AI refinement within the supported v1 capabilities defined in REQ-003 through REQ-005.

## Acceptance Criteria

- [ ] For each format (STL, OBJ, and 3MF), a user can open an existing model and inspect it by rotating and zooming the viewport.
- [ ] For each format (STL, OBJ, and 3MF), the import pipeline produces editable geometry that a user can refine through the manual editing workflow defined in REQ-003 through REQ-005, within the supported v1 capabilities.
- [ ] For each format (STL, OBJ, and 3MF), a user can refine the imported geometry through the conversational AI editing workflows defined in REQ-003 through REQ-005, within the supported v1 capabilities.
