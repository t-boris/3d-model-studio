## Statement

In v1, open and display STL, OBJ, and 3MF models with standard viewport navigation and import them as editable geometry for the manual and conversational workflows in REQ-003 through REQ-005. Support Core 3MF and Production extension assemblies. Resolve referenced model parts within the package, apply all relevant transforms, and expand the assembly into one indexed editable mesh while retaining the object, component, and build-item relationships needed for REQ-009. Apply the unsaved-changes prompt in REQ-008 before replacing the active model. Preserve the active workspace and edits if Open is canceled or fails.

## Acceptance Criteria

- [x] Users can open, orbit, zoom, and edit STL, OBJ, Core 3MF, and 3MF Production models through the supported manual and conversational workflows. Each import produces indexed geometry with stable face identifiers and shared vertex references.
- [x] STL and OBJ imports prompt for the source unit. Core 3MF uses the declared model unit and defaults to millimeters when it is omitted. 3MF import applies build-item and component transforms.
- [x] A multipart Production fixture saved by each of Bambu Studio and Orca Slicer opens with all referenced build geometry in the expected physical positions and dimensions. Each expanded mesh accepts a supported manual edit and a supported conversational edit.
- [x] A missing, invalid, cyclic, or external model-part reference causes a clear import error and preserves the active workspace and its edits.
- [x] Before Open replaces a model with unsaved geometry or pin changes, Save continues only after a successful save, Discard Changes continues without saving, and Cancel stops Open. Canceling the save dialog, file picker, or unit selection, or encountering a save or import failure, leaves the active workspace and edits intact.

## Implementation evidence

I-1 verified STL, OBJ, Core 3MF and both Production fixtures in the Debug macOS app. Each opened in SceneKit, orbited, zoomed and accepted a picked-point edit along Z. STL and OBJ prompted for the source unit and were opened in millimeters. The Core fixture displayed its declared centimeters, and the Bambu Studio and OrcaSlicer files rendered both occurrences. A single scroll could previously make the mesh disappear. Bounded field-of-view zoom kept the mesh visible while zooming in and back out. A missing-part import named the missing model part and preserved the edited OrcaSlicer mesh, selected point and camera view.

`Tests/run-assembly-checks.sh` verifies shared indices, stable face IDs, default millimeters, nested transforms, mirrored winding, mixed units, repeated-object isolation, and expected per-occurrence bounds on the Bambu Studio 02.09.01.70 and OrcaSlicer 2.5.2 saves. It exercises manual and scripted conversational edits, rejects fourteen invalid packages over an edited, pinned workspace, and checks both canceled unit choices. `Tests/run-manual-edit-checks.sh` and `Tests/run-provider-checks.sh` verify the edit paths across the remaining imports. Authenticated provider operations remain part of I-5. Fixture coordinates and hashes are recorded in `Fixtures/Import/README.md`.

## Replacement acceptance

I-7 routes toolbar and menu Open through the workspace guard. Tests/run-workspace-file-checks.sh verifies the save result before the Open picker appears, discard without a write, and cancellation before picking a file. Canceled and failed saves, canceled and failed pickers, failed reads, and canceled and failed source-unit choices keep the previous model identity, edited mesh and pins. An interrupted discard leaves the workspace dirty. A successful save followed by a canceled picker keeps it clean. Tests/run-assembly-checks.sh continues to exercise the 14 invalid assembly replacements through the guarded path.

## Current I-7 replacement verification

In the arm64 Debug build, Open prompted before replacing the edited assembly. Canceling its save panel retained the model and prompted again on the next Open. After Save, the replacement picker opened and the archive already contained the edited geometry and width pin. Discard Changes followed by a canceled picker, a canceled OBJ source-unit sheet, an out-of-range unit conversion, or an unsupported version-99 editable archive left the active assembly and its pending edits in place. The workspace-file suite also covers failed pickers and failed saves, and the assembly suite confirmed all 14 invalid package replacements and both canceled unit choices retain the edited model and pins.

## Review viewport evidence

The native Debug app showed a view cube that tracked orbit. Clicking its top face aligned the camera to the model’s top plane. Home View restored the default oblique orientation and zoom. Orbit retained SceneKit camera navigation, and scroll magnification remained available in editing modes.
