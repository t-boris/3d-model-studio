## Statement

In v1, open and display STL, OBJ, and 3MF models with standard viewport navigation and import them as editable geometry for the manual and conversational workflows in REQ-003 through REQ-005. Support Core 3MF and Production extension assemblies. Resolve referenced model parts within the package, apply all relevant transforms, and expand the assembly into one indexed editable mesh while retaining the object, component, and build-item relationships needed for REQ-009. Apply the unsaved-changes prompt in REQ-008 before replacing the active model. Preserve the active workspace and edits if Open is canceled or fails.

## Acceptance Criteria

- [ ] Users can open, orbit, zoom, and edit STL, OBJ, Core 3MF, and 3MF Production models through the supported manual and conversational workflows. Each import produces indexed geometry with stable face identifiers and shared vertex references.
- [ ] STL and OBJ imports prompt for the source unit. Core 3MF uses the declared model unit and defaults to millimeters when it is omitted. 3MF import applies build-item and component transforms.
- [ ] A multipart Production fixture saved by each of Bambu Studio and Orca Slicer opens with all referenced build geometry in the expected physical positions and dimensions. Each expanded mesh accepts a supported manual edit and a supported conversational edit.
- [ ] A missing, invalid, cyclic, or external model-part reference causes a clear import error and preserves the active workspace and its edits.
- [ ] Before Open replaces a model with unsaved geometry or pin changes, Save continues only after a successful save, Discard Changes continues without saving, and Cancel stops Open. Canceling the save dialog, file picker, or unit selection, or encountering a save or import failure, leaves the active workspace and edits intact.
