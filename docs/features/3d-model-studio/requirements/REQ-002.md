## Statement

In v1, open and display existing 3D models with standard viewport navigation and allow their subsequent refinement.

## Acceptance Criteria

- [ ] A user can open a supported existing 3D model and inspect it using rotation and zoom.
- [ ] An imported model can proceed into the manual and conversational editing workflows within the supported v1 capabilities.
