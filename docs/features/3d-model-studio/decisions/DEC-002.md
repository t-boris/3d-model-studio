## Context

Both imported-model refinement and conversational model creation are included in v1.

## Alternatives

1. Shape editing without dimensional accuracy or printability checks.
2. Exact dimensions with manufacturing validation performed separately by the user.

## Decision

Require exact dimensions and geometry checks for 3D printing in v1.

## Reason

The user explicitly selected dimensional accuracy and printability checks as mandatory first-version outcomes.

## Consequences

V1 must support dimensional control and geometry validation for 3D printing. Basic visual appearance remains sufficient.
