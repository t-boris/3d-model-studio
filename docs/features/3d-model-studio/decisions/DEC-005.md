## Context

DEC-002 requires dimensional accuracy in v1. REQ-003 and REQ-004 cover precise dimensions in conversational and manual workflows for new and imported models. F-003 identified that the specification did not define whether an explicit dimension remains in force after the operation that sets it.

## Alternatives

1. Treat every explicit dimension as a target for the current operation only.
2. Automatically retain every explicit dimension as a constraint until the user changes or removes it.

## Decision

In v1, an explicit dimension applies only to the operation that sets it by default. Users can explicitly pin a dimension on a new or imported model to preserve it across subsequent manual and AI edits. The constraint remains in force until the user changes or unpins it.

## Reason

Users can preserve dimensions that matter to the model while keeping routine edits free of constraints they did not choose to retain.

## Consequences

Resolve F-003 and update REQ-003 and REQ-004. Provide explicit controls for pinning and unpinning dimensions. Check requested dimensions when applying the current operation and check pinned dimensions before applying each subsequent manual or AI edit. Use the documented numerical tolerance for both checks. If a proposed edit violates a pinned dimension, reject the edit and identify the conflicting dimension.

## V1 measurements

Width, depth and height are the X, Y and Z spans of vertices referenced by model faces, measured in model coordinates. Measure and enter lengths in micrometers, millimeters, centimeters, meters, inches or feet. Compare the proposed physical span to the inclusive interval from target − 0.01 mm to target + 0.01 mm for each requested and pinned dimension. A pin change that resizes the surface must satisfy all remaining pins before either geometry or pins change.

## Direct editing

The shared workspace edit transaction prepares point movement, surface reshaping and extrusion from the current model. It compares each moved point’s signed axial offset or extrusion-normal displacement with the explicit distance in millimeters and checks every current pin against the proposed surface bounds before publishing. Manual distances expire after the operation. Set Once and Change Pin use the same transaction for numerical spans.

## Current plan I-2 evidence

Tests exercised the inclusive ±0.01 mm endpoints and rejection just outside them for surface spans and the displacement of each direct tool, including on centimeter Core 3MF. All six explicit units passed. A manual edit prepared against a model with no pins was checked against pins added before application. The multipart checks confirmed that rejection preserves geometry, occurrence ownership and pins. Native Set Once accepted successive heights, and Change Pin displayed the new value in centimeters.
