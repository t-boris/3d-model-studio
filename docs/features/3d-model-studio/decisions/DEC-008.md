## Context

The README describes Codex, Claude, and Antigravity as candidate agents and omits exact dimensions and geometry checks for 3D printing. DEC-003 requires all three integrations, and DEC-002 requires both dimensional accuracy and geometry checks in v1.

## Alternatives

1. Update the README to state the confirmed v1 scope and identify agent integration methods as an open technical question.
2. Keep the README brief, remove the outdated wording about candidate agents, and link directly to the approved v1 specification.

## Decision

Update the README to state that Codex, Claude, and Antigravity are required in v1 and that users can switch agents in settings. Include exact dimensional control and geometry checks for 3D printing in the v1 scope. Record integration methods for the three agents as an open technical question.

## Reason

Readers should be able to see the confirmed v1 commitments and the unresolved integration question directly in the README.

## Consequences

The README describes the approved v1 scope and links to I-5 for technical verification of the three integrations. The update resolves the README contradiction recorded in F-001. REQ-003, REQ-004, REQ-006, and REQ-007 retain their approved wording.
