## Context

REQ-007 defines the geometry checks. Q-005 determines how their results affect Core 3MF export under REQ-009.

## Alternatives

1. Показать дефекты и разрешить экспорт после явного подтверждения.
2. Экспортировать текущую сетку без проверки и предупреждения.

## Decision

Allow Core 3MF export only if the mesh being exported passes all REQ-007 checks. If any check fails, block export and show the failing checks and affected faces and edges.

## Reason

Boris selected option A, making a passing result mandatory for slicer export.

## Consequences

Users must correct the reported defects and obtain a passing result before exporting the mesh.
