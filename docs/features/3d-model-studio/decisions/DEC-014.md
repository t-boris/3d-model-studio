## Context

REQ-007 defines the geometry checks. Q-005 determines how their results affect Core 3MF export under REQ-009.

## Alternatives

1. Show defects and allow export after explicit confirmation.
2. Export the current mesh without a check or warning.

## Decision

Allow Core 3MF export only if the mesh being exported passes all REQ-007 checks. If any check fails, block export and show the failing checks and affected faces and edges.

## Reason

Boris selected option A, making a passing result mandatory for slicer export.

## Consequences

Users must correct the reported defects and obtain a passing result before exporting the mesh.

## Export validation

c09f5ea checks the workspace snapshot and the assembled mesh read from the exact temporary package that will be written. Faces and vertices are mapped back to original workspace IDs for the print inspector. An open block with one face removed reported its three boundary edges and their incident face IDs, retained the destination bytes, and exported after repair. A separate regression began with a printable block and a large placement transform. Readback exposed triangles collapsed by coordinate conversion and blocked export.

## Implementation evidence

REQ-009 implements this decision. The Core 3MF export command checks the serialized geometry, reports affected faces and edges and preserves the destination on failure. I-8 verified that repair allows export.
