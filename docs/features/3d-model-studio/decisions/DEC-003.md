## Context

The original request named candidate agents without confirming which integrations were mandatory.

## Alternatives

1. Ship v1 with one agent integration and select the agent after capability assessment.
2. Ship v1 with Codex, Claude, and Antigravity integrations.

## Decision

Include Codex, Claude, and Antigravity in v1, with agent switching in settings.

## Reason

The user explicitly selected support for all three agents over a single-agent first release.

## Consequences

All three integrations are required for v1; their supported integration methods and modeling capabilities still require technical verification.

## Implementation evidence

Codex uses OpenAI Codex CLI 0.172.0 with an explicit GPT-6.2 model. Claude uses Anthropic Claude Code 2.1.332 print mode with Sonnet or Opus. Antigravity uses Google's 0.1.24 SDK with an explicit Gemini model and a finish-only policy. The native Settings choices, prepared runtime images, geometry boundary, sources and evidence for each provider are recorded in [Providers/README.md](../../../../Providers/README.md). The production routes passed offline transport checks. Authentication, entitlement and live model behavior remain unverified.
