## Context

F-005 identifies a gap in REQ-005. Selected faces define the target of an AI edit, but an operation such as extrusion can also move a shared vertex or rebuild an adjacent unselected face. DEC-007 governs which geometry the agent may access. This decision governs which proposed changes the application may apply.

## Alternatives

1. Allow operation-specific changes to directly adjacent unselected faces when needed to preserve connectivity. Require confirmation for any other change outside the selection.
2. Reject edits that would affect unselected faces or their topology. Leave the model unchanged and identify the faces the user needs to add to the selection.

## Decision

In v1, require explicit user confirmation before applying any selection-based AI edit that changes unselected faces or their topology. Show the affected region before requesting confirmation, including when the changes are needed to keep neighboring geometry connected.

## Reason

The user can review the full extent of the proposed change while still being able to complete operations that require changes outside the selection.

## Consequences

Update REQ-005 to require the application to show the affected region and obtain explicit confirmation before applying a proposed AI edit that changes any unselected face or its topology. Moving a shared vertex counts when it changes an unselected face. If the user declines, the model remains unchanged. Existing dimensional checks still apply.
