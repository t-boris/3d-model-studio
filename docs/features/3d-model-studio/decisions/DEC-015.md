## Context

The current importer expands a 3MF assembly into a shared editable mesh. DEC-010 requires Core 3MF export in millimeters.

## Alternatives

1. Export the edited geometry as a single mesh object and build item.
2. Preserve the imported 3MF object, component, and build-item structure in the Core 3MF export.

## Decision

Preserve the source object and component hierarchy and build items when exporting an edited 3MF import. Export the current geometry of each instance.

## Reason

The selected option preserves the imported assembly structure through editing and export.

## Consequences

Retain the link between edited geometry and the source assembly across save and reopen. Represent cross-part references within Core 3MF while preserving the assembly hierarchy and physical placement.
