## Context

The current importer expands a 3MF assembly into a shared editable mesh. DEC-010 requires Core 3MF export in millimeters.

## Alternatives

1. Export the edited geometry as a single mesh object and build item.
2. Preserve the imported 3MF object, component, and build-item structure in the Core 3MF export.

## Decision

Preserve the source object and component hierarchy and build items when exporting an edited 3MF import. Export the current geometry of each instance.

## Reason

The selected option preserves the imported assembly structure through editing and export.

## Consequences

Retain the link between edited geometry and the source assembly across save and reopen. Represent cross-part references within Core 3MF while preserving the assembly hierarchy and physical placement.

## Implementation evidence

I-1 records the build item and ordered component path to each imported leaf, its source object, original vertex indices and stable face IDs. A mixed-unit fixture places the same leaf three times. A manual edit and an offline conversational proposal moved a corner of one occurrence while both siblings kept their positions. Editable-file acceptance and Core 3MF export verification belong to I-7 and I-8.

## Manual topology edits

Use the imported face ID range and additional face ID ranges to associate current triangles with each occurrence. Extrusion keeps the cap face IDs and assigns the wall face IDs to the selected occurrence. The current triangle corners identify the vertices needed for that occurrence, including duplicated cap vertices. Commit b367f9a verified that sibling occurrences keep their geometry, the archive retains the associations, and further extrusion can use generated wall triangles after reopening. This verifies the mappings used by the editable archive. Core 3MF writer and slicer checks belong to I-8.

## Source-independent editable saves

I-7 retains the version-1 archive layout. The optional assembly lives in the saved indexed mesh along with the face ID allocator. Tests/run-workspace-file-checks.sh reopens an edited three-occurrence assembly after deleting the test copy of the source package. Each restored build and component path reaches the expected leaf object, every current face has an occurrence, and another extrusion on a saved wall assigns the new faces to the same occurrence. I-8 will exercise the Core 3MF writer with these mappings.

## Core export

The writer converts each build and component translation from its referencing part’s unit to millimeters and retains its linear basis. Each leaf’s current world vertices are mapped back into its local frame. Mirrored occurrences reverse local triangle order. Identical variants of a source object can share a Core resource. Edited variants receive separate resource IDs, including their referencing parents. The export suite verified that extrusion on the mirrored middle block leaves both siblings on their original shared resource, directly and after reopening an editable save.
