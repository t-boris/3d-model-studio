## Context

F-010 documented the earlier developer setup, which required Docker Desktop, locally built runtime images and credentials supplied through the launch environment. DEC-003 requires Codex, Claude and Antigravity in v1. The [current provider guide](../../../../Providers/README.md) describes native setup in Settings. End-to-end release verification with live providers remains open.

## Alternatives

1. Users install and start Docker Desktop, build the provider images from the repository, and supply credentials through the app’s launch environment.
2. Users install and start Docker Desktop, then use the app to download prebuilt provider images, authenticate, and verify each connection.

## Decision

In v1, users install 3D Model Studio, launch it from Finder, and connect Codex, Claude, and Antigravity through the app’s interface. The app prepares the required provider components. Setup requires no separate Docker installation.

## Reason

This gives users a single setup flow for all three required agents and removes the need to build provider images or configure the app’s launch environment.

## Consequences

Verify that the app can provision the required components and complete authentication for each provider. On a clean Mac without Docker Desktop installed, release acceptance must demonstrate that a user can install the app, launch it from Finder, connect all three agents through the app, and complete a conversational modeling operation with each.

## Current plan I-5 implementation

The shared ModelStudio scheme produced a universal Release app with arm64 and x86_64 slices. Its Runtime folder contains the installer, pinned archive manifest, hash-locked wheels list for each architecture, Antigravity adapter and subprocess sandbox profile. Tests/RuntimePackageChecks.py --app verified each packaged file against the checkout and exercised the packaged installer for all six provider and architecture pairs with local archives. Settings tests a geometry-free challenge against the selected model before saving a key in macOS Keychain. Installation on a clean Mac without Docker Desktop, launch from Finder, live authentication and one applied live modeling operation per provider on that Mac remain release acceptance.
