## Context

The current importer rejects references to other model parts. The [3MF Production extension](https://3mf.io/wp-content/uploads/sites/55/2025/02/3MF_Production_Extension_v1_1_2.pdf) defines references to objects in other parts of the same package.

## Alternatives

1. Limit v1 import to single-part Core 3MF.
2. Support the 3MF Production extension for assembly geometry in v1.

## Decision

Support Production extension assembly import in v1. Resolve model-part references, apply their transforms, and expand the referenced geometry into one editable mesh while retaining the assembly structure needed for export.

## Reason

The selected option lets users open and edit multipart slicer models directly.

## Consequences

Verify geometry import and editing with multipart fixtures saved by Bambu Studio and Orca Slicer.
