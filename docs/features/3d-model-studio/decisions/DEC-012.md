## Context

F-009 identified a gap between REQ-008, which defines what an editable save restores, and REQ-002, which preserves the active workspace when opening another model is canceled or fails. Neither requirement defines how to protect unsaved edits when a replacement succeeds or the user quits.

## Alternatives

1. Prompt the user to save, discard changes, or cancel before replacing the active model or quitting.
2. Automatically save a separate draft containing geometry, units, and pinned dimensions. Allow replacement or quit after a successful draft save, and let the user restore or delete the draft.

## Decision

In v1, before replacing the active model or quitting, prompt the user with Save, Discard Changes, and Cancel if the model has unsaved geometry changes or if an explicitly pinned dimension has been added, changed, or removed.

## Reason

The prompt gives users control over whether to keep or discard their work and uses the existing editable-save workflow without requiring draft storage or a recovery interface.

## Consequences

Extend REQ-008 to cover both new and imported models. Save must successfully persist the edited geometry, model unit, and pinned dimensions before the requested action proceeds. Cancel, canceling the save dialog, or a save failure must stop the action and leave the active model open with its edits intact. Discard must allow the requested action to proceed without saving. If opening the replacement is canceled or fails, the active model must remain open with its edits intact, consistent with REQ-002.
