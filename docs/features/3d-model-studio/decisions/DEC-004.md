## Context

F-002 found that REQ-002 left the required v1 import formats and their editability undefined. DEC-001 requires imported models to support manual and conversational refinement.

## Alternatives

1. Open and view STL, OBJ, and 3MF, with manual and AI-assisted editing available for STL and OBJ.
2. Open, view, and edit STL and OBJ manually and through AI. Defer 3MF support.

## Decision

In v1, users can open, view, and edit imported STL, OBJ, and 3MF models both manually and through AI within the supported v1 editing capabilities.

## Reason

Supporting the same viewing and editing workflows across all three formats gives users a consistent path from import to refinement and makes the v1 compatibility promise testable.

## Consequences

Update REQ-002 to name all three required formats. For each format, verify that a user can open the model, rotate and zoom the view, and refine the imported geometry through the manual and conversational workflows defined in REQ-003 through REQ-005. The import pipeline must provide editable geometry for each format.
