## Context

The first-release workflow needed a confirmed boundary.

## Alternatives

1. Prioritize editing imported models.
2. Prioritize AI creation of new models.

## Decision

Include both imported-model editing and conversational model creation in v1, followed by manual and conversational refinement.

## Reason

The user explicitly selected both workflows in a limited scope.

## Consequences

The first release must support both entry points, with limited modeling capabilities in each.

## Implementation evidence

The SwiftUI conversation sheet supports creation from an empty workspace, continuation of a draft, and iterative revision of an active model. Answers accompany the original instruction. Applying a proposal makes its indexed surface available for the next revision. The interpreted provider harness exercised clarified creation and revision on each of the three routes, and two successive revisions of each STL, OBJ and 3MF fixture on each route. Runtime provider and interactive UI verification remain outstanding.
